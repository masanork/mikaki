# Security policy

## Project status

sakimori is an experimental development project. There are no supported releases, and the local implementation is not intended to protect real accounts or user data.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is enabled for this repository. Do not include vulnerability details in a public issue or discussion.

If private reporting is unavailable, open an issue with only a request for a private reporting channel. Do not include exploit steps, affected account details, credentials, or other sensitive information in that issue.

Reports should identify the affected commit and include a minimal reproduction using local or synthetic data. Do not test against systems or accounts that you do not own or have permission to assess.

There is no service-level response commitment or security bounty.
