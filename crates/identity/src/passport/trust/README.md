Both Rust and OpenSSL 3 independently verified the real root/CRL signatures.
The 2019/2024 CSCA keys use explicit P-384 parameters and their ECDSA signature
AlgorithmIdentifiers contain NULL parameters. Certificate/CRL signature verification
accepts absent/NULL ECDSA parameters while verifying the exact original TBS bytes;
CMS ECDSA parameters remain required to be absent. Explicit EC domain parameters
are compared mathematically with the supported standard curves before using a key.

`p256-parameters.der` and `p384-parameters.der` are standard curve constants,
generated by OpenSSL 3 using `ecparam -name prime256v1` / `secp384r1` with
`-param_enc explicit -no_seed -outform DER`. They contain no keys. Accepted explicit
domains must match field, coefficients, generator and order, and cofactor 1 if
present. Optional generation seeds do not alter those mathematical parameters.

## Refreshing revocation evidence

The runtime never follows document-supplied URLs. A reviewed app update refreshes
the bundled CRL. Download a proposed replacement from the fixed official URL into
a temporary file, inspect thisUpdate/nextUpdate/AKI and verify its signature with
the pinned key before replacing evidence and updating its provenance. For example:

```sh
curl --fail --location https://pkddownload1.icao.int/CRLs/JPN.crl -o /tmp/mikaki-jpn-next.crl
openssl x509 -inform DER -in jpn-2024.der -out /tmp/mikaki-jpn-root.pem
openssl crl -inform DER -in /tmp/mikaki-jpn-next.crl -text -noout
openssl crl -inform DER -in /tmp/mikaki-jpn-next.crl -verify -CAfile /tmp/mikaki-jpn-root.pem -noout
```

Use OpenSSL 3. The Rust trust tests must also pass after replacing the snapshot.
The real-snapshot test derives its test time from thisUpdate and tests expiry
separately, so historical fixtures remain reproducible. Production always uses
the current native system clock and degrades to stale/unknown after expiry.

A release build can instead set `MIKAKI_PASSPORT_CRLS` to a JSON array of canonical
padded standard Base64 DER complete CRLs. This replaces the bundled snapshot;
`[]` intentionally means no revocation evidence. Bounds and signatures are still
enforced by the shared verifier. It does not add CSCA roots or expose a WebView import API.
No network refresh, rollback protection, link-certificate path discovery or other
country's root enrollment is implemented in this slice.
