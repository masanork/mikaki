# ADR 0010: プロジェクト名称を御垣（MIKAKI）にする

- 状態: 採用
- 決定日: 2026-09-23

## 背景

プロジェクトを公開した後、近い分野で「防人（SAKIMORI）」の名称が使われ、商標登録出願中との公表が確認された。開発初期で利用者や外部連携が限られるため、名称の混同を避ける変更を早期に行う。

## 決定

- プロジェクトの名称を「御垣」、ASCII表記を`Mikaki`、識別子表記を`mikaki`とする。
- GitHubリポジトリ、文書、crate、Worker、ローカル設定、テストfixtureで使うプロジェクト識別子を`mikaki`へ揃える。
- 過去のGit commitは書き換えない。外部で保持された旧リポジトリURLやclone済みremoteは新しいURLへ更新する。

## 影響

既存の配備設定で`SAKIMORI_*`環境変数を設定している場合は`MIKAKI_*`へ移行する。crate名とWorker名も変更されるため、参照するアプリや開発スクリプトを同時に更新する。現時点では本番配備前であり、既存の利用者向け互換層は設けない。

## 検討した選択肢

- `sakimori`を継続する: 同名・近接分野の製品との混同を避けにくいため採用しない。
- 新名称を追加調査して決める: 候補「御垣」は読みと意味がプロジェクトに合い、名称確認も済んだため、ここで決定する。
